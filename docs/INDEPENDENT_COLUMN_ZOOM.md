# 两栏独立缩放

日期：2026-11-01。分支：`codex/independent-column-zoom`。

用户反馈点击一栏缩放会带动另一栏。原实现让 `setZoom`、PDFKit 倍率通知和开启同步的入口同时更新两栏倍率；“同步滚动”因此同时控制缩放。

现在缩放命令只更新目标栏，开启同步只对齐纵向阅读位置。工具栏按钮、右键菜单、触控板缩放均独立；⌘=、⌘-、⌘0 作用于当前活动栏，菜单名称也明确注明当前栏。左右互换后，工具栏继续对应视觉上的左右位置。

页面居中、阅读锚点、分隔线拖动和侧栏开合的宽度适配继续使用原有视口事务。布局宽度变化仍会让受影响栏重新适配。
