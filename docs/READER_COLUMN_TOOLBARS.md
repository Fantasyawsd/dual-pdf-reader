# 栏内工具栏、页码胶囊与独立滚轮缩放

本轮在 `codex/independent-column-zoom` 的基础上完成双栏阅读器的栏级工具与页码交互，并集中修复了首轮实现中暴露的交互冲突。

## 顶栏

- 模式选项卡统一为 **原文 / 译文 / 分屏**。
- 互换按钮与同步按钮仅在 **分屏** 模式显示；单栏模式下自动隐藏。
- 同步按钮只保留链接图标，不再附带“同步 / 独立”等文字。
- 顶栏只保留模式切换、分屏专属按钮和右侧边栏开关；页内搜索在按 ⌘F 或点击栏内搜索时展开。

## 每栏独立工具栏

左右两栏各自持有 `ColumnToolbarView`，模式、颜色、标注和撤销历史互不共享：

- 一级工具条：大纲目录、双页并排、单页/连续滚动、自适应宽度、抓手漫游、指针选择；中部为 **阅读 / 批注 / 形状** 文本选项卡；右侧为页内搜索与随手笔记。
- 当前模式使用黑色（深色模式为白色）下划线指示，未选中项无下划线。
- 阅读模式二级工具条高度为 0；批注模式提供高亮、下划线、删除线、画笔、橡皮擦、文本；形状模式提供矩形、椭圆、直线、箭头。
- 调色控件只有一个调色盘按钮，点击后弹出色彩网格，不在工具栏平铺颜色方块。
- 撤销/重做使用每栏自己的 PDF 标注历史栈；工具栏按钮与标准 `⌘Z` / `⇧⌘Z` 都会作用于当前栏。
- 所有新增图标按钮及模式选项卡都带中文悬浮提示；自定义悬停按钮只重建自己的 tracking area，保留 AppKit 原生 tooltip 区域。

### 窄栏响应式

- 宽度不足时，固定工具收进 `…` 溢出菜单，不会直接消失。
- 宽度极窄时，模式选项卡切换为当前模式菜单，仍可进入阅读/批注/形状。
- 批注/形状工具在窄栏中会压缩按钮与间距，并可从溢出菜单访问撤销、重做和颜色。

### 文本批注

- 选择文本工具后点击页面会弹出文本输入气泡；输入内容后按 Return 或“添加”创建自由文本注解，不再写入不可编辑的占位文本。

## 搜索、大纲与侧边栏

- 从某一栏的搜索按钮打开搜索时，只在该栏内查找，并在输入框占位符中显示“在左栏/右栏中查找”；⌘F 仍搜索当前可见的所有栏。
- 大纲/缩略图浮层会从发起操作的那一栏一侧展开，并锁定显示该栏的目录或缩略图；浮层打开时点击另一栏的大纲按钮会切换来源，而不是直接关闭。
- 右侧边栏开关保留在顶栏最右侧，`⌘I` 同样有效。
- 标准 `⌘Z` / `⇧⌘Z` 由本地按键监视器作用于最近操作的可见栏；搜索框、文本批注气泡和笔记编辑器等文本输入场景会让位给输入控件自身的撤销。

## 底部页码胶囊

- 每栏底部居中显示悬浮圆角卡片：上一页、页码输入框、总页数、下一页。
- 在 PDF 上滚动时平滑淡入；最后一次滚动 2 秒后淡出隐藏；鼠标悬停时取消隐藏计时，离开后重新计时。
- 打开文档、切换到该标签页或在栏底部移动鼠标时也会短暂显示，避免页码入口不可发现。
- 页码输入框按 Return 直接跳转，自动限制在 1...总页数。

## 鼠标所在栏的 ⌘ + 滚轮缩放

- 阅读器安装本地滚轮事件监视器，按鼠标位置解析所在栏；即使事件落在 PDFKit 内部滚动视图上，也能被稳定接住。
- 缩放只作用于该栏，范围固定为 0.25x–5.0x；触控板捏合同样受此范围约束。
- 缩放后仍由 `PDFViewportCoordinator` 恢复该栏阅读锚点并保持页面水平居中。

## 当前已知边界

- 栏内自由标注（高亮、下划线、删除线、画笔、形状、文本）写入当前 PDFKit 文档，属于会话内标注；与文献库中持久化的划词高亮/笔记仍是两套数据。关闭并重新打开 PDF 后自由标注会消失，栏内撤销也只覆盖当前会话。
- 要彻底统一，需要把自由标注迁入 `PaperAnnotation`（含样式与几何字段）或新增持久化标注模型，并让渲染、橡皮擦、撤销和笔记列表共用同一数据源；这是下一步的架构级改动。
