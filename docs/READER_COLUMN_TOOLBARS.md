# 顶栏共享批注工具栏与页码胶囊

## 顶栏

- 模式选项卡统一为 **原文 / 译文 / 分屏**；互换与同步按钮只在分屏模式显示。
- 两栏共用一条批注工具栏，直接包含指针、高亮、下划线、删除线、画笔、橡皮擦、文本、矩形、椭圆、直线、箭头、单一调色盘以及撤销/重做。
- 选择工具或颜色后同时作用于左右两栏；撤销/重做作用于最近操作的栏。
- 顶栏右上角的收起按钮隐藏**整条顶栏**（模式选项卡、共享工具行和右侧按钮一起隐藏），阅读区随之上移。
- 顶栏隐藏后，顶部中央保留一个向下箭头用于恢复；也可以使用快捷键 ⌘⇧T，或菜单“视图 → 隐藏/显示阅读器顶栏”恢复。
- 页内搜索在按 ⌘F 或点击栏内搜索按钮时展开。

## 每栏阅读工具栏

左右两栏各自保留一条阅读控制工具栏，不再包含阅读/批注/形状模式选项卡或二级标注工具条：

- 大纲目录、单页/连续滚动、自适应宽度、抓手漫游、指针选择、页内搜索、随手笔记。
- 所有图标按钮都有中文悬浮提示；自定义悬停按钮只重建自己的 tracking area，保留 AppKit 原生 tooltip。
- 宽度不足时阅读工具收进 … 溢出菜单，不会直接消失。

## 标注

- 高亮、下划线、删除线、画笔、文本和形状保存在 PaperAnnotation 中，重新打开 PDF 后从模型重新渲染，并与划词摘录和右侧笔记列表共用数据。
- 指针工具可选择、移动和调整形状；Delete/⌫ 删除，方向键微调 1pt，⇧+方向键微调 10pt，Esc 取消选择。
- ⇧ 拖动矩形/椭圆手柄保持正方形/圆形；箭头可拖动端点。
- 橡皮擦在一次拖动结束后批量删除命中标注，并作为一个撤销步骤；⌘Z / ⇧⌘Z 和共享工具栏的撤销/重做都通过模型操作。

## 底部页码胶囊

- 每栏底部居中显示上一页、页码输入框、总页数、下一页。
- 滚动时淡入，最后一次滚动 2 秒后淡出；悬停时保持显示。
- 每栏胶囊使用该栏自己的文档和滚动位置计算页码；同步滚动完成后两栏都会刷新。
- 页码输入框按 Return 跳转，并限制在 1...总页数。

## ⌘ + 滚轮缩放

- 按鼠标所在栏独立缩放，范围 0.25x–5.0x。
- 缩放后恢复该栏阅读锚点并保持页面水平居中。
