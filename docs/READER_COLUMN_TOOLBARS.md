# 栏内工具栏、页码胶囊与独立滚轮缩放

本轮在 `codex/independent-column-zoom` 的基础上完成双栏阅读器的栏级工具与页码交互。

## 顶栏

- 模式选项卡统一为 **原文 / 译文 / 分屏**。
- 互换按钮与同步按钮仅在 **分屏** 模式显示；单栏模式下自动隐藏。
- 同步按钮只保留链接图标，不再附带“同步 / 独立”等文字。
- 顶栏不再保留重复的栏内页码、缩放、搜索与侧栏按钮；这些入口下沉到各栏工具栏。

## 每栏独立工具栏

左右两栏各自持有 `ColumnToolbarView`，状态互不共享：

- 一级工具条常驻：大纲目录、双页并排、单页/连续滚动、自适应宽度、抓手漫游、指针选择，中部为 **阅读 / 批注 / 形状** 文本选项卡，右侧为页内搜索与随手笔记。
- 当前模式使用黑色（深色模式为白色）下划线指示，未选中项无下划线。
- 阅读模式二级工具条高度为 0；批注模式提供高亮、下划线、删除线、画笔、橡皮擦、文本；形状模式提供矩形、椭圆、直线、箭头。
- 调色控件只有一个调色盘按钮，点击后弹出色彩网格，不在工具栏平铺颜色方块。
- 撤销/重做使用每栏自己的 PDF 标注历史栈，一栏的编辑不会影响另一栏。

标注直接写成 PDFKit 原生注解。高亮/下划线/删除线使用相对 annotation bounds 的 `quadrilateralPoints`（页面绝对坐标会导致注解不可见）；画笔使用 page-sized bounds 与页面坐标路径；矩形、椭圆、直线、箭头与自由文本均通过真实鼠标拖拽验证。

## 底部页码胶囊

- 每栏底部居中显示悬浮圆角卡片：上一页、页码输入框、总页数、下一页。
- 在 PDF 上滚动时平滑淡入；最后一次滚动 2 秒后淡出隐藏；鼠标悬停时取消隐藏计时，离开后重新计时。
- 页码输入框按 Return 直接跳转，自动限制在 1...总页数。

## 鼠标所在栏的 ⌘ + 滚轮缩放

- `InteractivePDFView` 捕获 Command + 滚轮并直接返回，不再把事件交给 PDFKit 翻页。
- 缩放只作用于接收事件的那一栏，范围固定为 0.25x–5.0x；触控板捏合同样受此范围约束。
- 缩放后仍由 `PDFViewportCoordinator` 恢复该栏阅读锚点并保持页面水平居中。
