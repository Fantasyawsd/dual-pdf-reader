# PDF 阅读器修复记录

双栏阅读在模式切换、分隔线拖拽和侧栏开合时，会把 PDFKit 的布局通知当作用户滚动，导致跳页、缩放重置和进度写错。本次修复隔离了布局期间的通知，恢复每栏独立的 PDF、阅读位置和缩放状态，并修复审查报告中的全部 20 类问题。

基线：本地 `main`，`b519816`。修复分支：`codex/pdf-reader-fixes`。原始复现证据见 [审查报告](PDF_READER_BUG_AUDIT.md)。

## 实现与兼容性

- `ReaderLayoutViews.swift` 在窗口、画布与分隔线改变尺寸前后通知控制器；控制器合并 AppKit/PDFKit 的布局过程，恢复位置后再接受滚动与进度通知。
- `ReaderState` 为可选元数据，保存两个物理槽位对应的 PDF、逻辑阅读位置、缩放及布局偏好。旧版本的 `meta.json`、旧 `ReadingPosition` 均可继续解码。
- 自动布局造成的临时最小宽度限制不覆盖用户期望比例。侧栏在窄窗口保持至少 280pt，PDF 栏继续受现有最小宽度限制。
- 搜索任务使用代次标识，并在服务发布结果及导航选区时验证 PDFDocument 身份。
- 点选任一 PDF 会更新活动文档，目录和缩略图随之切换。
